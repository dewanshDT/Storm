---
date: 2026-10-21
summary: The Storm app on Windows and Linux, one Claude login for all your hosts, and fixes that keep your edits safe.
---

- **The Storm app on Windows and Linux.** On Windows, `install.ps1` installs
  it with a Start-menu entry (`-App`), or unzip
  `storm-app-windows-x86_64.zip` and run `storm.exe`. On Linux, `install.sh
  --app` installs the `storm-app` package on Debian and Ubuntu (also `sudo apt
  install storm-app` from the Storm repository) and the tarball into your home
  directory anywhere else. One copy runs at a time, it finds servers on your
  network, and an image on the clipboard pastes into a session.
- **One Claude login for every host.** Paste a `claude setup-token` once in
  **Settings › Claude login**, tick the hosts that may use it, and Claude
  Code sessions there sign in with it. Needs this release's storm-server and
  storm-runtime on each host; an older host keeps its own login.
- **The installer no longer asks for agent logins.** Claude Code signs in from
  the app, OpenCode from a shell session on the host. The installer's **MCP
  only** option (`--mcp`) is now offered.
- **An MCP server on your own network can be plain `http://`** when its
  address is a local IP or `localhost`. The app warns that its token is sent
  unencrypted; sign-in with OAuth still needs `https://`.
- **Your edits are safer:**
  - text typed while a save is in flight is never dropped;
  - an offline edit to a note deleted elsewhere comes back as a new note
    instead of disappearing;
  - a note keeps its identity when it is renamed or copied outside Storm;
  - a byte-order mark at the top of a note no longer hides its frontmatter.
- **The server is stricter at its edges:** an error says only what happened
  (a 404 means not found), every relay connection caps a message at 16 MiB,
  attachments are served sandboxed, and a rename that only changes case
  works.
- **Backups** link unchanged files to the previous backup instead of copying
  them, and refuse to run when the vault root looks empty.
- OpenCode sessions keep the workspace's own instructions file while still
  ignoring its project configuration.

Upgrade storm-server, storm-runtime on every host, storm-relay if you run
one, and the apps.
