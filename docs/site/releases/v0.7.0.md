summary: Sessions named by their agent, image paste, and terminal settings.

- Sessions take their name from the agent's own terminal title, with the
  agent's logo and a working / idle badge.
- **Paste or drop images** into a session on desktop, the web and Android —
  including Gboard's image keyboard.
- **Settings › Terminal:** text size, line spacing and padding.
- Android 16's back gesture goes to the parent page.
