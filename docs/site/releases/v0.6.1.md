v0.6.0 was tagged but never published; this release carries it.

- **The interactive installer** sets up the server and app, a Runtime Host,
  or everything, on Linux or macOS, pairs your phone and enrolls the host.
  Re-run it to upgrade, check status or uninstall.
- The server runs on macOS, as you, with your notes in `~/Storm`.
