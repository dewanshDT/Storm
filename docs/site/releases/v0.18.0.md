---
date: 2026-11-17
summary: A terminal that follows light themes, a token estimate for every note, Storm remembering which vault you write to, 12 new themes in 6 families, and fixes to terminal copy, paste and focus.
---

- **The terminal can be light.** In a light app theme, a shell now follows
  it live. An agent session stays dark until its program asks the terminal
  for its colours, then switches to whichever brightness the app is in at
  that moment. **Settings › Terminal › Colours** picks **Match app** (the
  default) or **Always dark**.
  - A new session's environment carries `COLORFGBG`, for a program that
    reads it instead of asking.
  - The brightness your program was last told is remembered on the host,
    so opening the same session on a second device, or after a reload,
    shows it the way the program actually drew it rather than dark.
- **A token estimate for every note.** The Properties panel shows a
  **Size** row, `~2.4k tokens · 1,812 words · 10.2k chars`, that updates as
  you type. Selecting text in the editor or the reader shows the
  selection's own estimate underneath. The launcher's context-note chip
  shows it too, as `Title · ~1.1k tokens`. It's an estimate, about ±15%.
- **Storm remembers which vault you write to, per workspace.** The
  launcher now preselects the **Write to** vault (or no writes) you last
  used for a host and workspace, marked **last used here**. Changing
  **Where** applies the remembered choice for the new workspace, until you
  touch Write to yourself. A host's details in **Settings › Agents &
  hosts** list what's remembered per workspace, with **Forget**.
- **12 new themes, in 6 families.** Beside Storm and SlowFlow, six new
  families are inspired by Catppuccin, Gruvbox, Nord, Rosé Pine, Solarized
  and Tokyo Night, each with a light and a dark variant. **Settings › This
  device › Appearance** picks **System**, **Light** or **Dark**, and a card
  per family with a live preview. Every theme's terminal palette is derived
  to pass a contrast check, and **Settings › About & health** credits each
  inspiration.
- **Fixes:**
  - copied terminal text keeps the spaces between words instead of
    running together;
  - terminal copy and paste work reliably: a quick drag focuses the
    terminal before you press ⌘C, a stuck input-method state no longer
    swallows keys, and the explicit keys (⌘C/⌘V on a Mac, Ctrl+Shift+C/V
    elsewhere) always copy and paste, while Ctrl+A and Ctrl+V keep going
    to the agent;
  - ⇧⌘N, ⌘N and ⌘\ on macOS, and Ctrl+Shift+N on Linux and Windows, reach
    Storm even while a terminal has focus; a New session that can't start
    now says why;
  - the **Write to** vault menu widens to fit vault names instead of
    truncating them;
  - toasts float in the bottom-right corner on a desktop, and their action
    reads clearly in every theme;
  - Command Code's login also answers to `cmd`, `cmdc` and `commandcode`,
    not only its full name;
  - the Wrote panel's header spans the panel, and a note whose body opens
    with a matching title isn't shown twice;
  - pasting into a terminal on the web goes through the browser's own
    paste, so it works over plain HTTP and a multi-line paste still keeps
    its line breaks;
  - opening a session from the sidebar always gives its terminal the
    keyboard, including the second time you click back to it.

Upgrade storm-server, storm-runtime on every host, and the apps.
storm-relay is unchanged. The server adds one table to `agent.db`,
`workspace_prefs`, on its own at first start (`CREATE TABLE IF NOT
EXISTS`, no existing table touched and nothing to migrate); `auth.db`,
`gateway.db` and each vault's `index.db` are unchanged. A v0.17.0 host or
server keeps working: the new `terminal_brightness` and `rerun_of` fields
on starting a session, and `terminal_answered` on status, are all
optional, and anything older ignores them. Mixed versions of the host,
server and app work together.
