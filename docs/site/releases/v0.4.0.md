---

- **Storm v2:** an activity rail for Notes and Agents, one global Settings,
  and launch straight back to where you were.
- **One account.** Storm is single-user; older servers keep their oldest
  owner when they upgrade.
- **The loop:** start a session from a note, give it one vault it may write
  to, and see what it wrote — each note it touched links back to the session.
- **Integrations:** connect MCP servers such as Notion or Linear once; agents
  use them without ever receiving the credential.
